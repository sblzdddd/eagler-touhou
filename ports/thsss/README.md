# THSSS · 东方夏夜祭

东方夏夜祭的浏览器 Runtime 由 .NET NativeAOT 工程产出，经共用启动器加载。本目录是作品入口和适配记录，Runtime 放在 `build-eagler/`。

- [开发与构建](docs/DEVELOPMENT.md)
- [逐项适配与自动检查](ADAPTATION.md)
- [源码目录与检查入口](../../docs/architecture/source-layout.md)

游戏与浏览器宿主的源码在 [THSSS-WASM](https://github.com/sblzdddd/THSSS-WASM)。原版数据和音乐由使用者提供，通过启动器的内容准备接入。
